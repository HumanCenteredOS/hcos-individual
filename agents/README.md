# AI Agents

HCOS uses specialized AI agents rather than one monolithic assistant.

Each agent has a clearly defined responsibility while sharing a common constitution and ontology.

Current planned agents include:

- A001 Companion Agent
- A002 Capacity Agent
- A003 Love Agent
- A004 Human Map Agent
- A005 Voice Agent
- A006 Truth Agent
- A007 Understanding Agent
- A008 Wisdom Agent
- A009 Healing Agent
- A010 Stewardship Agent

Together these agents form the HCOS Individual Operating System.
