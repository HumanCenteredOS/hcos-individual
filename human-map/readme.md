# Human Map

The Human Map is the evolving representation of an individual's current state.

The Human Map may include:

- Capacity
- Pressures
- Supports
- Hustle
- Flow
- Protection
- Extraction
- Perception
- Identity
- Relationships
- Health
- Purpose
- Voice
- Reality Shifts
- Current Principle
- Current Foundation
- Current Method
- Current Action
- Stewardship

The Human Map is continuously updated through conversation and reflection.
