# HCOS™ Actions

## Purpose

Actions are the visible expression of Principles.

They answer:

> **What should I do today?**

Actions transform understanding into practice.

---

# Examples

- Tell the truth.
- Listen with curiosity.
- Repair relationships.
- Rest.
- Establish boundaries.
- Seek support.
- Reduce unnecessary suffering.
- Protect another person's dignity.

---

# Design Philosophy

Actions should be:

- intentional
- sustainable
- compassionate
- reality-based
- consistent with HCOS™ Principles

Small consistent actions create lasting Reality Shifts.

---

# AI Guidance

Never overwhelm the individual.

Recommend one meaningful action before suggesting another.
