# Reality Engines

Reality Engines are the primary educational experiences within HCOS.

Each Reality Engine guides individuals through a specific Reality.

Current Reality Engines include:

R00 Capacity

R01 Love

R02 Protection

R03 Purpose

R04 Awareness

R05 Truth

R06 Understanding

R07 Compassion

R08 Faith

R09 Discipline

R10 Action

R11 Healing

R12 Human Flourishing

Each Reality Engine follows a standardized architecture based upon:

- Principle
- Foundation
- Method
- Action
- Stewardship
